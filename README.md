# Python Fundamentals

A collection of small Python examples and exercises focused on the language's core syntax and string operations.

## Topics Covered

The repository includes examples involving:

- Variables and basic expressions
- String values and formatting
- String slicing, including step and reverse slicing
- Escape characters and special characters
- Sequence operators
- String interpolation and formatted strings

## Getting Started

### Requirements

- Python 3

Check your installation:

```bash
python --version
```

Run an individual exercise from the repository directory:

```bash
python helloworld.py
python variables.py
python strings.py
```

Some filenames contain spaces; quote those filenames when running them from a terminal.

## How to Use This Repository

Each Python file is a focused example. Read the code, run it, and modify the values to observe how Python evaluates the expression or string operation.

## Scope

This is a learning repository, not a packaged Python library or production application.
